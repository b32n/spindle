# E2E fixtures

Small, synthetic files used by the file-I/O specs (`e2e/*/file-io.spec.ts`, `file-errors.spec.ts`,
`image-*.spec.ts`). They contain no private data. Regenerate everything with:

```bash
node scripts/testing/make-fixtures.mjs   # needs LibreOffice (`soffice`) and python3 + Pillow
```

The office files are **real office-suite output**: the script writes flat-ODF sources (`src/`) and converts them
headless with `soffice --convert-to xlsx|docx`, so the bytes are what LibreOffice writes (not a Spindle round-trip).
Regenerating changes the bytes of the converted files (timestamps), so only regenerate when a fixture really changes.

| File | Provenance | What it exercises |
|---|---|---|
| `styled-multisheet.xlsx` | `src/styled-multisheet.fods` -> LibreOffice Calc "MS Excel 2007 XML" | 3 sheets (`Sales`, `Costs`, `Notes ünï`); formulas incl. cross-sheet (`=Sales!D5*0.2`) and absolute refs; number formats: currency `$#,##0.00`, percent `0.0%`, date `yyyy-mm-dd`, custom `#,##0.0" kg"` and `00000`; merged `A7:D8`; header style (bold, white font, blue fill, centred, thin borders), italic+fill banner, red underlined text, right alignment, top border on the total; custom column widths. (LibreOffice's headless conversion drops frozen panes, hence the next file.) |
| `exceljs-frozen.xlsx` | Library-generated with `exceljs` by `make-fixtures.mjs` | Frozen panes (1 column + 2 rows), column widths, bold header, a formula (`=SUM(B3:C3)`), 40 rows. |
| `rich-document.docx` | `src/rich-document.fodt` -> LibreOffice Writer "MS Word 2007 XML" | Title + H1/H2/H3, bold/italic/underline and all three, bullet list with a nested item, numbered list with a nested item, a 2x3 table with bold header, a hyperlink, an embedded PNG image (`logo.png`), a page break, header text and a footer with a PAGE field, document title property. Note LibreOffice stores the page break inside the image paragraph (see `D-FIO-05`). |
| `quoting.csv` | Hand-written (generated by the script) | Embedded commas, escaped quotes, newlines inside quoted cells, empty field, padded text, `007` (leading zeros), `1e3`, a text cell starting with `=`. |
| `unicode.csv` | Hand-written | UTF-8 with CRLF line endings: accents, German, Japanese, Chinese, emoji (incl. ZWJ family and flag), Arabic and Hebrew (RTL). |
| `semicolon.csv`, `tabs.tsv.csv` | Hand-written | Semicolon (European Excel) and tab-delimited exports; the product has no delimiter detection, so these document current behaviour. |
| `logo.png` | Generated by `make-fixtures.mjs` (pure-Node PNG encoder), 120x60 | Image for docs/slides uploads and the embedded image in `rich-document.docx`. |
| `logo.jpg`, `logo.gif`, `logo.webp` | Pillow conversions of `logo.png` | Slides image upload variants. |
| `logo.svg` | Hand-written | Slides image upload (SVG is accepted by `accept="image/*"`). |
| `notes.txt` | Hand-written | A plain-text file for "wrong file type" error tests. |

Not committed (generated inside the tests, to keep the repo small): the 10,000-row CSV, the multi-MB DOCX,
the 4000x3000 PNG, truncated/corrupt/empty variants.

## `fonts/`

`LiberationSans-{Regular,Bold}.subset.ttf`: Liberation Sans (SIL OFL 1.1) subset to Latin-1 + common punctuation with
`pyftsubset`. Embedded by `e2e/support/visual.ts` under every font family the demos request so screenshots do not
depend on the fonts installed on the machine.
